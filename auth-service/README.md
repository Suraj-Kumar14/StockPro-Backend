# Auth Service

`auth-service` is the identity and access service for StockPro.

## Purpose

This service is responsible for:

- user registration
- email OTP verification
- login with JWT
- forgot-password flow
- profile update flow
- role storage in JWT

## Tech Stack

- Java 17
- Spring Boot 3.2.2
- Spring Security
- Spring Data JPA
- H2
- Java Mail
- JWT (`jjwt`)
- Swagger / OpenAPI
- Eureka Client
- Spring Boot Admin Client

## Default Configuration

| Item | Value |
| --- | --- |
| Application Name | `AUTH-SERVICE` |
| Port | `8081` |
| Swagger | `http://localhost:8081/swagger-ui/index.html` |
| H2 Console | `http://localhost:8081/h2-console` |

## Roles Issued By This Service

- `ADMIN`
- `INVENTORY_MANAGER`
- `WAREHOUSE_STAFF`
- `PURCHASE_OFFICER`

These role values are stored in the JWT `role` claim.

## Main Endpoints

### Public

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/auth/user/welcome` | Basic health check |
| `POST` | `/auth/user/register-request` | Send OTP for registration |
| `POST` | `/auth/user/register-user` | Verify OTP and create account |
| `POST` | `/auth/user/login` | Login and get JWT |
| `POST` | `/auth/user/forgot-password/request` | Send OTP for password reset |
| `POST` | `/auth/user/forgot-password/verify` | Verify reset OTP |
| `POST` | `/auth/user/forgot-password/reset` | Reset password |

### Protected

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/auth/user/{email}` | Get user by email |
| `GET` | `/auth/user/all` | List all users |
| `POST` | `/auth/user/update-profile/{email}` | Update profile |
| `POST` | `/auth/user/verify-email-update` | Verify changed email with OTP |
| `DELETE` | `/auth/user/deactivate/{id}` | Deactivate user |
| `POST` | `/auth/user/logout` | Logout placeholder endpoint |

## JWT Contract

The JWT generated by this service includes:

- subject: user email
- `userId`
- `role`

Downstream services and the API gateway use the same JWT secret for validation.

## Important Configuration Properties

```yaml
server:
  port: ${PORT:8081}

app:
  jwt:
    secret: ${JWT_SECRET:...}
    expiration-ms: ${JWT_EXPIRATION_MS:3600000}

eureka:
  client:
    service-url:
      defaultZone: ${EUREKA_URL:http://localhost:8761/eureka}
```

Mail and Google OAuth settings are also read from environment variables.

## How It Connects With Other Services

- Registers with `eureka-server`
- Sends actuator data to `Admin-server`
- Issues JWT tokens used by `api-gateway` and downstream services
- Provides login endpoint for the frontend
